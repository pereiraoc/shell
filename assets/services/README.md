# Ícones dos serviços do NAS (Nexus › Server › Services)

Logos de marca em silhueta branca sobre transparente; o shell pinta na cor do tema
(`ColouredIcon`), igual aos ícones da aba Launch. Origem: [Simple Icons](https://simpleicons.org)
v15.22.0 (CC0; marcas são dos donos), `fill="#fff"` e `<title>` removido.

O nome do arquivo é o slug do Simple Icons; `server.js` (`serviceArt`) mapeia stack/unidade → slug.
Serviço sem logo no Simple Icons (navidrome, stalwart, netalertx, dispatcharr, netbird, odysseus, sshd...)
usa um símbolo Material (`serviceGlyph`).
